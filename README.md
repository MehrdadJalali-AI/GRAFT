# GRAFT

Code for GRAFT graph-oversampling experiments.

## Repository contents

- `code/graft/` — core data, model, and training modules
- `code/run_experiments.py` — experiment runner
- `code/make_fig4.py`, `code/make_figures_tables.py` — result-visualization utilities
- `data/` — processed graph datasets
- `results/`, `results_v1/` — experiment outputs and configurations

Manuscript materials, PDFs, submission archives, and manuscript-related documents are maintained locally and intentionally excluded from this public repository.
