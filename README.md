# GRAFT

Code for GRAFT graph-oversampling experiments.

## Repository contents

- `code/graft/` — core data, model, and training modules
- `code/run_experiments.py` — experiment runner
- `code/make_fig4.py`, `code/make_figures_tables.py` — result-visualization utilities

Research data, experimental results, and manuscript materials are maintained locally and intentionally excluded from this public repository.
